# 01 - Components and Props

Neste módulo foram praticados os conceitos fundamentais do React combinados com a tipagem estática do TypeScript.

## 🎯 Conceitos Praticados

- Criação de componentes funcionais.
- Tipagem de `props` utilizando `interfaces` e `types`.
- Passagem de propriedades opcionais e valores padrão (_default props_).
- Desestruturação de `props`.

## 🚀 Como rodar este módulo

1. Instale as dependências:
   ```bash
   npm install
   ```

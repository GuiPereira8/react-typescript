# ⚛️ React & TypeScript: Fundamentos e Conceitos Avançados

> 🔄 **Repositório em constante atualização e evolução.**

Este repositório é o registro central dos meus estudos sobre o ecossistema **React com TypeScript**, focando na construção de interfaces reativas, componentização e aplicação de segurança de tipos com as melhores práticas do mercado.

Os exercícios e módulos teóricos são desenvolvidos com **Vite** e **TypeScript**, servindo como um guia prático de evolução.

---

## 🎯 Objetivos de Aprendizado

- **Tipagem Estática & Props:** Uso de `interface` e `type` para contratos de dados seguros em componentes funcionais.
- **Gerenciamento de Estado & Eventos:** Manipulação de estado reativo e manipulação tipada de formulários e cliques (`React.ChangeEvent`, `React.FormEvent`).
- **Hooks Nativos & Customizados:** Aplicação prática de `useState`, `useEffect`, `useContext` e desenvolvimento de Hooks reutilizáveis.
- **Gerenciamento Global & Testes:** Estudo sobre `Context API`, `Redux` e introdução a testes automatizados no React.

## 💻 Como executar os módulos localmente

1. Clone o repositório:
   ```bash
   git clone [https://github.com/seu-usuario/react-typescript.git](https://github.com/seu-usuario/react-typescript.git)
   ```
2. Acesse a pasta do módulo que deseja explorar:

   ```bash
   cd 01-evoluindo-projetos
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
